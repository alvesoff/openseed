Política de privacidade

Esta página explica o que acontece com dados pessoais quando você visita openseed.com.br. Ela descreve o site como ele é hoje, e o site de hoje é simples: não tem formulário, não tem cadastro, não usa cookie próprio e não roda ferramenta de análise de audiência.

Quem é o responsável

A OpenSeed é a responsável pelo tratamento dos dados descritos aqui. Para qualquer assunto de privacidade, escreva para contato@openseed.com.br ou chame no WhatsApp 16 99705-2711.

O que o site coleta por conta própria

Nada. Não há formulário de contato, campo de e-mail, área de login, cookie de sessão nem script de estatística. Você consegue ler o site inteiro sem nos informar coisa alguma.

O que terceiros podem coletar

Ainda assim, abrir qualquer página na internet envolve outras empresas. No caso deste site, quatro:

  • GitHub Pages. O site é hospedado lá. Como qualquer servidor, o GitHub registra requisições, o que inclui seu endereço IP e o navegador usado. Isso é do funcionamento da hospedagem, não é algo que a gente configure ou acesse.
  • Google Fonts. As fontes da página são carregadas dos servidores do Google. Para entregá-las, o Google recebe seu endereço IP. Nenhum cookie é definido por isso, mas a conexão acontece.
  • Cloudflare (cdnjs). A página inicial carrega de lá a biblioteca de animação GSAP. Para entregar o arquivo, a Cloudflare recebe seu endereço IP. Nenhum cookie é definido por isso. As demais páginas não fazem essa chamada.
  • Meta (WhatsApp e Instagram). Só entram em cena se você clicar nos nossos links de contato. A partir daí você está numa plataforma da Meta, sob as regras dela.

Nenhuma das quatro é opcional para o funcionamento do site como ele está montado hoje. Se isso mudar, por exemplo se passarmos a usar analytics ou um formulário, esta página muda junto, e a data no topo muda com ela.

Quando você fala com a gente

Se você nos procura pelo WhatsApp ou pelo Instagram, passa a nos informar coisas por vontade própria: nome, telefone, empresa e o que estiver querendo resolver.

Usamos isso para uma coisa só: responder você e tocar a conversa comercial. Não vendemos, não alugamos e não repassamos esses dados para terceiros com finalidade de marketing. A conversa fica guardada enquanto fizer sentido para o relacionamento e depois é descartada.

Seus direitos

A Lei Geral de Proteção de Dados (Lei nº 13.709/2018) garante que você pode, a qualquer momento, pedir:

  • Confirmação de que tratamos algum dado seu, e acesso a ele
  • Correção do que estiver incompleto ou desatualizado
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados para outro fornecedor
  • Eliminação dos dados tratados com base no seu consentimento
  • Informação sobre com quem compartilhamos seus dados
  • Revogação do consentimento

É só pedir por qualquer um dos canais acima. A gente responde em até 15 dias.

Segurança

O site é servido exclusivamente por HTTPS, com certificado válido, então a conexão entre o seu navegador e o site é criptografada. A biblioteca que vem de fora é carregada com verificação de integridade: se o servidor de terceiro entregar um arquivo diferente do esperado, o navegador recusa executar. Como não há banco de dados nem área logada, não existe base de visitantes para vazar.

Mudanças nesta política

Se o site passar a fazer algo diferente com dados, esta página é atualizada antes, não depois. A data no topo sempre reflete a última alteração real.
